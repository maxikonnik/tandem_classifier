# tandem_detector

Распознавание типичных сцен в видеозаписях тандемных парашютных прыжков.
Система размечает время и выдаёт JSON с таймкодами; монтаж в скоуп не входит.

## Целевые сцены

| Сцена | Как определяется |
|---|---|
| Интервью | Фаза на земле + речь в звуке + лицо при малом движении камеры |
| Отделение | Телеметрия: провал перегрузки с возвратом к 1g |
| Яркие моменты свободного падения | Обученная голова поверх признаков; 5 подкатегорий |
| Раскрытие парашюта | Визуально: скачок площади пятна, смена формы на куполообразную |
| Приземление | Визуально по семантике кадра |

Подкатегории ярких моментов: яркие эмоции, яркая жестикуляция, общий план,
общий план с манёврами пары, облёт пары оператором.

## Архитектура

Три стадии, разделённые артефактами на диске:

```
видео ──[извлечение]──> артефакты ──[анализ]──> scenes.json
           GPU              диск        CPU
        один раз                      секунды
```

Дорогой проход по видео выполняется один раз на прыжок. Вся логика детекции
работает поверх сохранённых признаков и переизмеряется за секунды, что делает
цикл разработки коротким.
