# Переобучение probe на 231 прыжке

**Дата:** 6 октября 2026
**Итог:** модель, обученная на 231 прыжке, по качеству **не отличается** от рабочей (153
прыжка). В рабочем коде остаются прежние веса `tandem/visual/deploy_probe.json`; новые
сохранены рядом как `tandem/visual/deploy_probe_231.json` — чтобы включить их, достаточно
заменить ими `deploy_probe.json`.

## Данные

- **Обучение:** все 231 размеченный прыжок на E: (метки из хранилищ разметчика, по
  content id, копии считаются один раз). 153 — прежний набор, 78 — новые:
  49 из `E:\V\Sep\св. падение`, 29 из `E:\V\10` (из них 22 DJI). 20 167 кадров,
  215 сессий.
- **Внешняя валидация:** `E:\claude\c` — 568 видео за 21–29 августа, ни одно не
  размечено и не совпадает с размеченными ни по содержимому, ни по имени файла в папке
  прыжка, ни по папке. Хендикам по имени (Курносов, хендикам/хедикам) — 44 видео —
  исключён. Телеметрия отобрала 94 кандидата; по кадрам подтверждены **50 внешних
  свободных падений** (ещё 8 оказались хендикамом без пометки в имени, 7 — ложные:
  салон, взлёт, земля, приземление).

## Результаты

### Перекрёстная проверка (leave-one-session-out), HSMM

Каждый прыжок оценивает модель, не видевшая его сессию. Доля в пределах 2 с на всех 231:
exit 99 %, drogue 97 %, deploy 98 %, breakoff 96 %.

Парное сравнение старой и новой модели на одних и тех же прыжках (старая на своих 153 —
LOSO, на новых 78 — честно отложенные). Метки, принятые разметчиком из черновика
старой модели без правки, исключены — они подыгрывают старой модели.

| граница | n | новая лучше / хуже (>0.25 с) | знак-тест p | ≤1 с: старая → новая | ≤2 с |
|---|---|---|---|---|---|
| exit | 167 | 5 / 4 | 1.00 | 87 → 87 % | 99 → 99 % |
| drogue | 181 | 6 / 6 | 1.00 | 86 → 87 % | 96 → 97 % |
| deploy | 224 | 13 / 7 | 0.26 | 84 → 86 % | 99 → 99 % |
| breakoff | 184 | 9 / 17 | 0.17 | 74 → 70 % | 94 → 96 % |

С метками из черновиков breakoff расходится сильнее (9 / 23, p = 0.02), но это
артефакт: старая модель «угадывает» метки, которые сама же и предложила.

### Валидация на E:\claude\c (50 незнакомых внешних падений, разметки нет)

Точность меряется по независимым сигналам: телеметрическому exit (акселерометр GoPro)
и гироскопному breakoff.

| | старая (153) | новая (231) |
|---|---|---|
| найден прыжок со всеми 4 границами | 50 / 50 | 50 / 50 |
| длительности фаз в пределах 1–99 перцентиля меток | 49 / 50 | 49 / 50 |
| exit ≈ акселерометр (GoPro, n = 38), ≤1 с / ≤2 с | 84 / 100 % | 76 / 97 % |
| breakoff ≈ гироскоп (n = 43), ≤1 с / ≤2 с | 53 / 74 % | 51 / 72 % |
| «прыжок» на неподтверждённых кандидатах | 14 | 15 |

Модели между собой совпадают в пределах 1 с на exit, drogue, deploy в 100 % случаев,
на breakoff — в 98 %; медиана расхождения 0.00 с.

## Решение

Новая модель не лучше: на перекрёстной проверке различия незначимы, на `E:\claude\c` —
почти полное совпадение, с небольшим отставанием по точному (≤1 с) exit и breakoff.
Рабочие веса не меняются. Рост с 153 до 231 прыжка, видимо, упёрся в потолок линейного
probe на замороженном DINOv2: дальнейший выигрыш — от архитектуры (временной контекст,
дообучение бэкбона) или от разметки breakoff по единому правилу, а не от объёма.

Побочная находка: в папках внешнего оператора бывает хендикам без пометки в имени —
файлы GH0199xx в корне папок «Алексей Д …», вложенные папки с именем пассажира
(«Илья/Илья»), «22.08.26 Дмитрий», «08.28 Владислав», GX010354 у «Эвелина Андрей Т.».
