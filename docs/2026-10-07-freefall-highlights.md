# Нарезка интересных моментов свободного падения

**Дата:** 7 октября 2026
**Код:** `tandem/highlights.py`, `tandem/visual/shot_scale.py` (+ веса `shot_scale.json`)
**Вход:** окно свободного падения [бросок дрога → раскрытие] — его уже находит probe.
**Выход:** список отрезков `{kind, start_s, end_s, score, source}` — таймкоды для монтажа.
Видеофайлы нарезок нужны только для оценки (страница `E:\claude\highlights_review`).

## Что ищем и чем

| момент | определение | сигнал |
|---|---|---|
| общий план (`wide`) | пара видна, но занимает ≤ 10 % кадра, ≥ 3 с подряд | доля кадра под парой |
| крупный план (`close`) | пара ≥ 30 % кадра, ≥ 2 с | доля кадра под парой |
| лицо крупно (`face`) | пара ≥ 45 % кадра, ≥ 2 с; ранжирование по улыбке GoPro | доля кадра + `smile%` GoPro |
| облёт (`orbit`) | поворот камеры ≥ 270° за 8 с, пара в кадре ≥ 75 % окна | гироскоп камеры |

Пороги долей — по примерам 10/20/30/50/70 % (лист примеров отправлен в чате): 30 % уже
читается как крупный план, 45–50 % — лица крупные. В свободном падении медианная доля
пары 13 %, 90-й перцентиль — 36 %.

**Доля кадра под парой.** Учитель — детектор RT-DETR (`PekingU/rtdetr_r50vd`, класс
person); пара = наибольшая группа пересекающихся рамок людей (так отсекаются соседние
парашютисты, а рамки у угла кадра — рука оператора — отбрасываются). Ученик — гребневая
регрессия на эмбеддинге DINOv2, который probe и так считает раз в секунду, так что в
продукте это бесплатно. Обучение: 1000 кадров свободного падения из 125 прыжков.

Перекрёстная проверка по прыжкам (5 фолдов, прыжок целиком в тесте), против RT-DETR:

| | |
|---|---|
| корреляция доли | 0.89, средняя ошибка 4.6 п.п. |
| полоса (нет/общий/средний/крупный) угадана | 76 % (ошибки — соседние полосы) |
| крупный ≥ 30 %: точность / полнота | 75 % / 77 % |
| лицо ≥ 45 %: точность / полнота | 78 % / 69 % |
| общий ≤ 10 %: точность / полнота | 69 % / 69 % |

## Облёт: гироскоп против визуального детектора

Сигнал гироскопа — модуль интеграла вектора угловой скорости за скользящее окно 8 с:
устойчивый поворот накапливается, покачивание головы гасится. У GoPro поворот почти всегда
вокруг оси 0 (рыскание), у DJI — вокруг оси 1.

Проверены два визуальных детектора на 66 прыжках (30 с сильнейшим поворотом по гироскопу,
30 случайных, 6 DJI):

1. **Сдвиг фона** (фазовая корреляция соседних кадров, 5 кадров/с, центр кадра
   замаскирован) — с гироскопом не коррелирует ни по одной оси GoPro (|r| ≤ 0.13);
   на рыбьем глазе, бестекстурном небе и смазанных при повороте кадрах оценка сдвига
   ненадёжна. Ни одного облёта не нашёл.
2. **Изменение кадра** (средняя косинусная дистанция эмбеддингов DINOv2 за 8 с) — с
   поворотом по гироскопу связан слабо (r = +0.20) и не отличает облёт от «карусели».

Гироскоп: на 19 окнах, которые он отметил, пара всё время в кадре; по раскадровкам
12 из 19 (63 %) — настоящий облёт (пару видно спереди, сбоку, со спины), 7 — «карусель»
(пара и оператор вращаются вместе: фон крутится, пару видно с одной стороны — тоже
динамичный кадр, но не облёт). **Вывод: облёт — по гироскопу**; визуальный вариант для
камер без гироскопа пока не работает.

## Лица и эмоции

GoPro пишет рамку лица и вероятность улыбки (FACE). Проверка по кадрам 35 моментов
«лицо ≥ 2 % кадра, улыбка ≥ 70»: **размер рамки GoPro не соответствует лицам в кадре**
(«2–3 % кадра» при крошечной паре), поэтому крупность лица берётся из доли кадра под
парой (≥ 45 %), а улыбка GoPro — только для ранжирования. Честная оценка эмоций требует
модели лиц (например, MediaPipe Face Landmarker: улыбка и открытый рот по губам — очки не
мешают); она не установлена — следующий шаг.

## Результат на 231 размеченном прыжке

Окно падения — человеческие метки; доля пары — голова на кэшированных эмбеддингах;
телеметрия — гироскоп и FACE.

| тип | прыжков с клипом | клипов |
|---|---|---|
| общий план | 174 (75 %) | 174 |
| крупный план | 93 (40 %) | 122 |
| лицо крупно | 93 (40 %) | 93 |
| облёт | 73 (32 %) | 73 |

В среднем 2 клипа на прыжок. Секунды падения по планам: пары не видно 21 %, общий 28 %,
средний 39 %, крупный 13 %.

**Проверка по кадрам** (середина клипа, 20 случайных клипов каждого типа):
общий план — 20/20 действительно общий; крупный план — 14/20 крупный, 6 ближе к среднему;
лицо крупно — 20/20 крупный план, лица хорошо видны в 12/20 (в остальных пара спиной
или боком); облёт — 12/19 по раскадровкам (см. выше).
